# 橘动 RALLY 演示说明

## 启动

在微信开发者工具中打开仓库根目录，点击「编译」。Mini Program 根目录为 `miniprogram/`，TypeScript 插件已配置。

Three.js r108 源码已随项目保存，演示无需安装或构建 npm。第三方源码及 MIT 许可位于 `miniprogram/vendor/`；Canvas 适配仅服务当前几何场景，不包含外部模型或纹理加载器。

TypeScript 输出目标为 ES5，开发工具开启 ES6 转译和增强编译，避免把可选链、空值合并及对象展开语法直接交给真机调试端。修改编译配置后，先结束旧的真机调试，执行「清缓存 → 清除全部缓存」，重新编译后再次启动真机调试。

需要运行兼容性回归检查时，先执行 `npm install`，再运行 `npm run check:device-syntax`。此检查覆盖所有页面的编译输出及 JavaScript 转译配置，不能代替真机调试。

## 推荐演示顺序

1. 首页右上角选择「管理员」，点击活动名称修改标题，点击日期调整活动日期。
2. 在「队伍」中修改队名和头像，点击成员调整队伍；可创建空队伍，再分配成员。
3. 回首页添加项目，保存名称、规则和详细地址。计划时间通过时间选择器立即保存。
4. 项目详情进入「地图选点」，拖动地图让中心定位针对准目标，或点击地图选点；填写入口和楼层说明后保存。
5. 添加参考图片和视频，预览图片及播放视频。媒体保存在设备，实际可保存大小受设备空间和微信本地文件限制影响。
6. 进入 3D 场地，拖动旋转、使用加减按钮缩放、点击立方标记选择项目。管理员通过位置选择器为项目设置预置场地点位。
7. 回首页切换「裁判」，进入项目，将项目状态设为进行中，开始队伍比赛，再标记完成并录入成绩。项目结束后仍能补录或修改成绩。
8. 切换「用户」查看队伍、项目和排行榜。在「我的」修改头像和昵称；可退出当前队伍后创建或加入其他队伍。
9. 查看队友地图，所有队友坐标均标注为模拟位置。项目详情「前往这里」调用微信原生地点导航。
10. 退出后重新进入，检查状态、成绩和比赛用时保留。「我的 → 恢复演示数据」可重置演示。

## 已验证

- TypeScript 严格检查通过。
- 微信官方 WXML、WXSS 编译器检查通过。
- Three.js Canvas 作用域初始化及几何体创建通过。
- 初始数据、创建项目、本机保存恢复、0 分与待评分区分检查通过。
- 交互逻辑检查通过：同分并列排名、单人单队、队长交接、管理员调配成员、角色操作限制、开始与完成计时、无效分数拦截、项目结束后补录成绩及项目删除。
- 开发者工具中已目视验证橙色首页、3D 场地渲染、缩放、跳转项目详情和用户视角计时。

## 仍需真机验证

- 地图拖动选点、地点搜索和原生导航；相关位置接口须在小程序管理后台具备使用权限与隐私声明。
- 相册/相机选择、头像选择、图片持久保存和视频播放。
- 不同机型的 WebGL 渲染、触摸旋转与标记点击。

## Demo 边界

三种角色共享当前设备的模拟数据，角色切换用于演示，不是账号权限认证。第一版没有后台、多人同步或真实队友位置共享。3D 场景是预置示意模型，不代表地图上的真实建筑，模型上传留待后续版本。
