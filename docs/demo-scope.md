# 团建助手 Demo 范围

## 已确认

- 交付可在微信开发者工具中交互演示的微信小程序，使用模拟用户和数据；暂不接真实多人同步与后台。
- 核心流程：管理员设置活动 → 用户组队 → 参与项目 → 裁判评分 → 查看排名。
- 活动包含多支队伍和多个团队项目，每支队伍可参加多个项目。
- 用户有头像和昵称；队伍有队名、头像和成员。
- 同一小程序提供管理员、用户和裁判演示角色切换入口。
- 用户通过队伍列表创建或加入队伍；每人在一次活动中只能加入一支队伍，创建者成为队长。
- 队长可修改队名和队伍头像，普通成员可退出，管理员可直接修改队伍信息和调整成员。暂不设置人数限制或加入审批。
- 管理员设置活动、项目并查看整体进度和成绩；裁判查看负责的项目，更新状态并录入和修改成绩。
- 各队每项目得分为 0～100 分，总榜累加，同分并列；待评分与 0 分区分，成绩修改后更新排名。
- 项目整体状态与每支队伍的参赛状态分开保存，状态由管理员或裁判手动更新。
- 展示计划起止时间、倒计时或已用时间；本机保存队伍、分数与进度，重新打开后保留。
- 地图使用模拟队友位置并明确标注，展示队友标记与项目地点导航入口。

- 计划时间用于项目倒计时；裁判点击开始、完成记录队伍实际用时，退出再进入仍正确计算，暂不支持暂停和恢复。
- 队伍完成后可以待评分；项目结束后仍可补录或修改成绩。结束项目不自动完成各队，存在未完成队伍时先提示确认并保留实际状态。
- 预置一场活动、三支队伍、四个项目及多种比赛状态；提供恢复演示数据按钮，操作前二次确认。
- 采用中文、清爽运动风，橙色为主色。
- 管理员可以为每个项目设置精确地点，通过地图选点并移动定位针调整坐标，填写地点名称及详细地址（如楼层、入口）。用户可以查看地点并打开导航。
- 管理员可以从相册选择每项目最多 6 张参考图片和 1 段视频，支持删除、替换；图片支持放大，视频支持播放，用户端和裁判端均可查看。
- Demo 的参考媒体保存在当前设备，不上传服务器。

- Demo 使用预置三维示意场地，展示建筑、道路、集合点和项目位置，支持旋转、缩放和点击标记查看项目；明确标注场地示意，精确地址和导航以地图坐标为准。
- 管理员可以在预置三维场景中设置项目位置标记，不提供模型编辑器。
- 后续版本增加管理员上传场地模型，本版不实现模型上传；不会根据地址自动生成真实场地模型。
- 第一版只管理当前一场活动，支持修改活动名称、时间，以及新增、编辑和删除项目。
- 删除已有成绩的项目前提示相关成绩会被移除。
- 暂不做多活动切换、历史归档和复杂裁判分配，预置裁判负责全部项目。
